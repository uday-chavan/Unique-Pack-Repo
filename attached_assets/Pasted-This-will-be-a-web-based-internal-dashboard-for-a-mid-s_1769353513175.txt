This will be a web-based internal dashboard for a mid-scale machinery + hardware business that handles:

Stock & inventory

Orders & sales

Purchase & suppliers

Transaction history

Customer management

Reports & analytics

User roles & security

🧠 TECH STACK (Simple & Powerful)

Tell Replit Agent to use:

Frontend: React + Tailwind

Backend: Node.js + Express

Database: PostgreSQL (or SQLite for demo)

Auth: JWT-based login

Hosting: Replit deployment

📦 CORE MODULES & FEATURES
1️⃣ Authentication & User Roles
Roles:

Owner / Admin

Sales Staff

Inventory Manager

Accountant

Features:

Secure login system

Role-based access control

Activity logs (who changed what & when)

2️⃣ Machinery Inventory Management

Track:

Machine ID / SKU

Name

Category (Lathe, Drill, CNC, Generator, Hardware Parts, etc.)

Brand / Model

Serial Number

Purchase Cost

Selling Price

Quantity in Stock

Warehouse Location

Supplier

Condition (New / Used / Refurbished)

Warranty Period

Last Updated

Features:

Add / Edit / Delete Machines

Low stock alerts

Stock movement history

Bulk import/export (CSV, Excel)

Barcode support (optional advanced)

3️⃣ Orders & Sales Management
Customer Orders:

Order ID

Customer info

Machine(s) ordered

Quantity

Price per unit

Taxes

Discounts

Total amount

Payment status (Paid / Pending / Partial)

Delivery status

Invoice generation (PDF)

Features:

Create new orders

Edit / cancel orders

Print invoices

Track delivery

Link orders to inventory

4️⃣ Supplier & Purchase Tracking

Track:

Supplier details

Purchase orders

Incoming stock

Cost history

Payment status

Features:

Auto-add stock when purchase completed

Supplier performance tracking

Outstanding payments list

5️⃣ Transaction Records System
Stored Data:

Transaction ID

Type (Sale / Purchase / Refund / Adjustment)

Related Order ID

Machine ID

Quantity

Cost

Date & Time

Payment Method

Staff Member

Notes

Features:

Filter by date, machine, customer, staff

Export reports

Audit logs

6️⃣ Customer Management

Track:

Name

Business Name

Phone / Email

Address

GST/Tax ID

Order History

Outstanding Balance

7️⃣ Reports & Analytics Dashboard
Graphs:

Monthly sales

Profit vs cost

Top-selling machines

Low-stock alerts

Supplier spending

Customer purchase trends

8️⃣ Notifications System
Low stock alerts on dashboard 
Payment pending reminders
Order delivery alerts
System updates
